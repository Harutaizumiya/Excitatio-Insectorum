# 任务身份

你是本任务的独立执行 Worker。禁止创建任何后台任务、线程或子 Agent。

## 目标与位置

- 总目标：完成 PRD 第一阶段 MVP。
- 你负责的子目标：实现班主任反馈入口、反馈管理、使用状况分析页面。
- 该子目标在整体方案中的位置：等待后端契约阶段门后执行。
- 前置阶段门：后端 API 契约与类型已确定。

## 交付物

- 产物：Ant Design/Refine 页面、查询 hooks、路由/导航、反馈表单及管理交互。
- 写入路径：`apps/web/src/features/admin/analytics/**`、`apps/web/src/features/admin/feedback/**` 及必要的干净路由/导航文件。
- 返回格式：结论、变更、验证、风险。

## 边界

- 可读取：全仓库、PRD、后端契约。
- 可写入：上述路径及主 Agent 明确分配的契约文件。
- 禁止触碰：工作区当前已修改的文件；不要修改 `apps/web-next/**`。
- 文件所有权：分析与反馈新目录独占；共享路由/导航只做最小增量。
- reserved slots：2，由主 Agent 记录，Worker 不修改。

## 背景与约束

- 已知事实：`apps/web` 为活动 Vite SPA；管理端使用 Refine + Ant Design 6.6.1；数据由 TanStack Query 管理。
- 用户偏好：管理后台高信息密度、低学习成本，文案只保留完成任务所需信息。
- 关键约束：先用 CodeGraph；写 antd 组件前按已核对的 6.x API；反馈状态危险/关键更新需明确确认；沿用现有空/错/加载状态；不发明接口。
- 与其他 Worker 的接口：只消费已通过阶段门的后端契约。

## 验收

- 完成标准：班主任可随时提交反馈；管理者可查看统计、反馈列表/详情并更新状态与备注；响应式可用。
- 必须运行的验证：目标 web typecheck、测试、lint、antd lint、`git diff --check`。
- 缺失信息时的处理：报告缺口，不猜测。
