# 任务身份

你是本任务的独立审查 Worker。禁止创建任何后台任务、线程或子 Agent。

## 目标与位置

- 总目标：验收使用状况分析与用户反馈第一阶段 MVP。
- 你负责的子目标：只读审查当前工作树中新功能的正确性、安全性、隐私、权限、契约一致性与回归风险。
- 该子目标在整体方案中的位置：主集成后的独立验收门。
- 前置阶段门：后端、Web 契约、管理 UI 和客户端采集已实现并通过基础检查。

## 交付物

- 产物：按严重度排序的发现清单；无问题时明确说明；附证据、建议验证和剩余风险。
- 写入路径：无，禁止修改任何文件。
- 返回格式：结论、发现、证据、验证、风险。

## 边界

- 可读取：全仓库、PRD、git diff、agent_team 状态。
- 可写入：无。
- 禁止触碰：所有文件；不执行迁移，不提交/推送，不创建后台任务。
- 文件所有权：只读。
- reserved slots：1，由主 Agent 记录，Worker 不修改。

## 背景与约束

- 已知事实：当前没有全局管理员角色，管理能力限定本班 HEAD_TEACHER；反馈提交允许有效教师；大屏身份从 token 推导；埋点失败应静默；用户已有前端改动必须保留。
- 关键约束：先用 CodeGraph；重点检查请求埋点是否递归/重复、401 刷新 Trace ID、页面/异常/心跳事件、隐私白名单、反馈班级边界、统计含义、PostgreSQL/SQLite 迁移一致性、前端与后端响应类型、空值/时间范围/状态更新。
- 与其他 Worker 的接口：只向主 Agent 报告，不修复。

## 验收

- 完成标准：覆盖 PRD 十项验收标准，指出阻塞上线的问题与非阻塞缺口。
- 必须运行的验证：优先复用并抽查目标 typecheck/test/lint；不执行迁移。
- 缺失信息时的处理：报告缺口，不猜测。
